# landing-fads-prototipo
Prototipo académico de landing para el Plan de Marketing de Fred Astaire Dance Studios Santiago. No es el sitio oficial.

## Cómo agregar fotos y videos reales

Suban los archivos a la carpeta [`media`](media/) con estos nombres; la página los muestra en lugar de las imágenes referenciales. Lo que no exista queda como está.

| Sección | Archivos |
|---|---|
| Tu primera clase | `primera-clase.jpg` |
| Clases | `estudio.jpg` |
| Instructores | `profe-1.jpg` a `profe-6.jpg` (los nombres se editan en la lista `EQUIPO` de [`index.html`](index.html)) |
| Eventos, Noches de salón | `evento-1.jpg` a `evento-3.jpg` |
| Eventos, Competencias | `competencia-1.jpg` a `competencia-3.jpg` |
| Eventos, En el estudio | `estudio-1.jpg` a `estudio-3.jpg` |
| Alumnos | `testimonio-1.mp4` a `testimonio-3.mp4` |
